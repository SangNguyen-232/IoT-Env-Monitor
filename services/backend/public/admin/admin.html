Each card shows the model proposal, reference rule and latest GPIO command. The INT8 model uses seven consecutive DHT20 samples to forecast 30 seconds ahead. SHADOW mode controls the fan using the saved thresholds. In AI mode, the controller checks the OR profile (30/28°C and 75/70% RH) and the softmax score before allowing an early start.

History export range

Leave the dates blank to export all retained history. Dates use your browser's time zone. The start is inclusive and the end is exclusive. To create forecast labels from JSONL, select a session recorded by the INT8 firmware. The importer requires seven input samples and a further 30 seconds of observations with the same fan command at each sample in the forecast interval.

The export uses a fixed upper record ID. Rows deleted during export, including expired rows removed by retention, may be missing from the file.
