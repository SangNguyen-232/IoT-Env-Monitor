How to read the forecast and the controller’s decision

The DHT20 takes a sample every 5 seconds. The firmware uses seven consecutive samples (about 30 seconds) to calculate trend slopes, the most recent rate of change, and variation around the trend. The INT8 model combines these features with the current temperature, humidity and GPIO command to propose an action 30 seconds ahead.

The reference rule uses OR logic with 30/28°C and 75/70% RH as its ON/OFF thresholds. HOLD keeps the previous command. In SHADOW, compare the model’s proposal with the GPIO command from your saved thresholds. The agreement figure counts how often the model and the current reference rule propose the same action.

In AI, an ON proposal with a score of at least 0.80 can start the fan early within the hysteresis band. The controller enforces the ON/OFF thresholds and 10-second minimum dwell time. It uses the threshold rules while collecting samples, after a model error, for readings outside the model’s range, or when the saved thresholds differ from the reference settings. An invalid or stale DHT20 reading switches GPIO10 OFF as soon as the controller detects it.
